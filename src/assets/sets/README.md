# Runtime Set packages

This directory is the single authoritative root for generated runtime-ready TFT Set packages bundled with the Flet app. Every direct child with a `manifest.json` is discovered automatically; there is no separate activation list.

A package is used only after strict local validation. Runtime Sets contain declarative JSON, localization and local PNG assets, never executable Set-provided Python or runtime network dependencies.

`sample_set/` is the deterministic fictional development package generated from `set_sources/specs/sample_set/`. Real packages are generated by the developer-only importer documented in `SET_AUTHORING_GUIDE.md`.

Useful commands:

```text
uv run tft-builder-dev validate-set src/assets/sets/<set_id>
uv run tft-builder-dev inspect-set src/assets/sets/<set_id>
uv run tft-builder-dev build-set set_sources/specs/sample_set src/assets/sets/sample_set --overwrite
```

Do not hand-edit generated runtime Set files. Regenerate them from the corresponding source input. For reviewed Sets, inspect `SET_REVIEW.md` first; `SET_OVERVIEW.md`, `data/review.json` and `reports/source_inventory.json` provide the lower-level generated details.
